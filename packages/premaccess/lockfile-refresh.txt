# In-range lockfile refreshes the fork carries on top of upstream.
#
# Each line: <directory> <package>. rebase-onto-upstream.sh runs
# `yarn up -R <package> --mode=update-lockfile` in <directory> after every rebase,
# because the replay takes upstream's lockfiles and a lockfile-only fix would be
# dropped as an empty commit (sharp 0.35.4 on the nested apps, 2026-10-13).
# Only versions inside the ranges the manifests already declare: anything that
# needs a forced version goes to "resolutions" in the root package.json.
#
# Retire a line once upstream's lockfile resolves a patched version on its own:
# the refresh then changes nothing, and check-security-holds.sh shows the alert fixed.
